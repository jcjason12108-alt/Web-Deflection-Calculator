Adds EVO, FDL, and Tier 4 web deflection shim calculators via shortcode.

== Description ==

LL706 Web Deflection Calculator provides the [web_deflection_calculator] shortcode for web deflection TIR and shim calculations.

== Installation ==

1. Upload the plugin folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the Plugins screen in WordPress.
3. Add the [web_deflection_calculator] shortcode to a page or post.
